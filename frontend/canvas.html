Lethean Desktop · Lit components

Web-Components port of the desktop window catalogue. Each window is a single customElement with a reactive state attribute — change it in DevTools and the window re-renders. Designed for handoff to Claude Code: one custom-element file per window, the template structure mirrors what a SwiftUI View or Tauri component would look like.

All phases complete — E0 chat · E1 welcome / settings / model browser · E2 benchmark / logs / telemetry · E3 integrations / tools · E4 network / fine-tune / fleet.
